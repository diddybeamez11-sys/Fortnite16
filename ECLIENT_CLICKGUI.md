# ECLIENT reference ClickGUI

The overlay menu was rebuilt to match the supplied reference screenshot: dark translucent game backdrop, top Search strip, centered rounded ECLIENT click gui panel, left category rail, compact module rows, gear settings action, and ON/OFF state text.

The implementation is in `app/src/main/kotlin/com/nexoraclient/ui/overlay/OverlayService.kt` and is wired into the existing `OverlayService`/`ModuleManager`.
